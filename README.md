# Viso Studio

A responsive marketing studio website built with Astro. It includes a home page and dedicated Services, Customer, Pricing, Blog, and Contact pages.

## Getting started

```sh
npm install
npm run dev
```

Astro starts the local development server at `http://localhost:4321`.

## Build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`.
